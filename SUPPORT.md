# Support

- **Usage questions and ideas:** open a GitHub Discussion.
- **Reproducible bugs:** use the bug-report issue template.
- **Security issues:** report privately through GitHub Security Advisories as
  described in `SECURITY.md`. Do not open a public issue.
- **Pull requests:** see `CONTRIBUTING.md`.

There is no commercial support or guaranteed response time. When asking for
help, include the `wimon --version` output, the OS, the board/target, the exact
command, and the complete error message. Remove real credentials, captures,
addresses and other personal data first.

`LICENSE`.
